# 考研知识速查

一个单文件、可离线使用的考研知识速查页面，覆盖英语、数学、政治、408 四个科目。

打开 `index.html` 即可使用（双击或直接访问线上地址），数据全部内嵌在页面里，**不联网也能用**。

## 功能

- **搜索**：中英文关键词都能搜，支持多关键词与高亮；可按学科 → 分类 → 章节三级筛选
- **英语**：2024 英语一考试大纲全部 5530 个词汇，附真题语料词频、大纲序号、语义分类与红宝书分级；另有高频词精讲熟词僻义、固定搭配、语法长难句、写作模板
- **中英翻译**：词库离线双向查询，可选联网整句翻译
- **数学**：140 条公式与结论，使用 LaTeX 排版（KaTeX 已内嵌，离线也正常显示）
- **政治**：马原、毛中特、史纲、思修法基核心考点与分析题答题方法
- **408**：数据结构、计算机组成原理、操作系统、计算机网络
- 收藏、随机抽查、按词频/字母排序

## 词频说明

词频指该词在约 200 套真题语料中出现的次数（已做词形还原），约 40 次以上为高频词。
它反映的是语料统计热度，**不等于某一年考了几次**。
